# MangaAgentsStudio-S

既存小説から、Strataが字コンテとNovelAI用プロンプトを作り、NovelAIでコマ画像を生成し、ページに組みます。ブラウザで完成ページとコマ別の文章を見ながら、直接編集またはStrataへ修正を依頼できます。

## 起動

WebUIの「制作AI」で **Strata／Grok** を切り替えられます。標準はStrata。Grokを使う場合は、このPCでGrok CLIへログインしてから選択してください。起動済みの対話画面へ操作を送る方式ではなく、アプリが独立した短いCLI処理を起動します。Grokを選ぶと対象の原作・台帳・指示がGrokのクラウドへ送られます。利用上限・費用はGrok側の契約に従い、NovelAIのAnlasとは別です。詳細は [Grokの利用](docs/guides/GROK_PROVIDER.md)。

キャラの衣装（最大10種類）と表情選択、キャラ／背景の送信プロンプト確認・1枚試し描きに対応しました。[操作と検証結果](docs/records/PROFILE_TRIALS.md)。NovelAIの小説画面の手順と4ページずつの依頼は [約20ページの原作案](examples/NOVELAI_20P_GUIDE.md) にあります。

1. 先にStrataを起動しておき（下の「Strataの準備」）、`start-studio.cmd` をダブルクリックします。このツールだけを起動します（Strataが応答しなくても起動し、その旨を表示します）。
2. ブラウザで **http://127.0.0.1:8765** を開きます。
3. 左の「＋」から小説を貼り付けて作品を作ります。試すための原作は `examples/` にあります（例：12ページ用の [迷子のカメラ](examples/lost-camera-12.txt)）。

Python 3.12、Pillow、psd-tools、別途構築したStrata（下の「Strataの準備」）を使用します。依存関係は `python -m pip install -r requirements.txt`。NovelAIの永続的APIトークン（設定 › アカウント › 永続的APIトークン。英語表示では User Settings › Account › Get Persistent API Token）を、ルートの `.env.example` をコピーして名前を `.env` に変えたファイルの `NOVELAI_API_KEY=` の後ろに書きます。手順はガイドの「はじめる前に」にあります。

`powershell -ExecutionPolicy Bypass -File Start-Studio.ps1` でも同じように起動できます。同じポートで二重起動しないでください。制作サーバーの端末でCtrl+Cを押すか、`powershell -ExecutionPolicy Bypass -File Stop-Studio.ps1` で停止します。Strataの停止は、Strataの手順に従います。

## Strataの準備

Strata（ローカルの制作AI）は、このリポジトリには含まれません。公式の手順で別に構築し、このツールからはHTTPで呼び出します。Grokだけを使う場合は不要です。

### このツールが求める条件

| 項目 | 条件 |
|---|---|
| 接続先 | `http://127.0.0.1:8080/v1/chat/completions`（OpenAI互換API。ポート8080固定、`studio/agent.py` の `ENDPOINT`） |
| 機能 | ツール呼出し（function calling）に対応していること。`reasoning_effort: none`（Thinkingオフ）を送ります |
| 出力 | 1回の応答で最大8,192トークンを要求します。字コンテ2ページで約2,500トークン |
| 入力 | 1回あたり約1.5万〜2万トークン、ページ割りは原作全体（最大9万文字）。コンテキストは128K以上を推奨 |
| 速さ | 1回の応答は180秒以内、1つの依頼は10分以内に終わる必要があります。遅いPCでは時間切れで止まります |
| モデル名 | `qwen3.8-flash-next-iq2_xs` を送ります（Strataは名前を問わず受け付けます） |

### 開発に使った構築（参考）

開発時に動作を確かめた構成です。これと同じでなくても、上の条件を満たせば使えます。

| 項目 | 内容 |
|---|---|
| 本体 | [Niko1221/Strata](https://github.com/Niko1221/Strata)、コミット 7695859、エンジン 0.1.43 |
| モデル | [ISTA-DASLab/Qwen3.8-Flash-Next-GSQ-RCO-GGUF](https://huggingface.co/ISTA-DASLab/Qwen3.8-Flash-Next-GSQ-RCO-GGUF) の IQ2_XS（リビジョン ed59f92、2ファイル計約68GB） |
| 構築コマンド | Strataのフォルダで `.\START-HERE.bat --setup --yes --family qwen --model IQ2_XS --context 262144 --vram-reserve-mib 1500 --experimental-speed-projection on --no-start` |
| 待受け | `127.0.0.1:8080`、コンテキスト256K、画像入力オフ |
| PC | GeForce RTX 4070 Ti SUPER（VRAM 16GB）、メモリ64GB。出力は約50〜100トークン/秒 |


### 起動のしかた

- `start-studio.cmd`（と `Start-Studio.ps1`）はこのツールだけを起動します。Strataは先に起動しておきます。Strataの起動は、Strataの起動手順か、次のコマンドです（Strataのフォルダで実行。設定ファイル名は構築時のものに合わせます）。

```powershell
.venv\Scripts\python.exe -u serve/server.py --engine strata --config strata-iq2_xs.json --host 127.0.0.1 --port 8080
```

- 起動の確認は `http://127.0.0.1:8080/health` です。`loaded` が `true` になれば使えます（初回は数分かかります）。

### 同じ状態になるか

同じ本体のコミット・同じモデルのリビジョン・同じ構築コマンドなら、モデルと設定は同じになります。ただし、次の点は揃いません。

- 速度。キャッシュや並列数の一部はGPUとメモリから自動で決まります。VRAMやメモリが少ないPCでは遅くなり、180秒の制限に当たることがあります。
- 本体の版。Strataの手順は最新版を取得します。上のコミットに合わせないと、動きが変わることがあります。
- 応答そのもの。温度0.2で呼ぶため、同じPC・同じ入力でも毎回少し違う結果になります。

## 作る・直す

利用者向けの使い方は、アプリ右上の **「使い方」** から別タブで開けます（[web/guide/index.html](web/guide/index.html)）。基本の流れ、NovelAIでの小説の書き方、このキットに渡す小説のコツ、画像生成のTipsの4ページです。以下は要点です。


1. 右パネルの「汎用」タブで、全作品共通のシステムプロンプト（構成・翻訳・点検・制作条件）を確認します。左の「＋」で原作を貼って作品を作り、「作品専用」タブの「絵柄」で11プリセットまたは自由入力を選びます。
2. 「1. ページ割り」で開始章と全体のページ数を指定し、原作を各ページへ割り振ります。表で確認・修正したら、「2. 字コンテ」で2ページだけ試し、良ければ「ページ割りの最後まで自動で作る」。日英の外見・口調・背景台帳とコマの文章を作成し、コマの日本語訳は保存後に自動で補います。
3. 共通設定やページのコマを開き、日英プロンプト・人物・話者・台詞を編集。翻訳ボタンで日本語→英語／英語→日本語を指定できます。画像へ送るのは英語なので、日本語を変更したら英訳を反映します。
4. 「コマ枠・コマ数を変更」で-Aの79種を含む枠を選び、コマを増減できます。追加コマを直接編集するか、「このページをStrataで改稿」で埋めます。共通変更を文章・台詞へ反映するときは全ページ改稿または口調だけの反映を使います。
5. 「全ページを生成・組版」でStrata点検→警告確認→NovelAI生成。警告は無視して続行できます。通常は未生成・設定変更のある画像だけを直列生成します。
6. 生成後も同じ欄を編集できます。「保存・組版」は画像APIを呼ばず文字・クロップを反映。「保存して再生成」は選択コマを描き直します。ページ別の生成、過去候補の再採用も可能です。
7. 「全ページを書き出す」で台詞あり／なしのPNG、またはレイヤーPSD＋確認PNGをZIPへ。いずれも台詞一覧md・設定JSON・配置情報を同梱し、バックエンドで作成します。
8. 「共通システム設定JSON」「全入力の設定JSON」を保存・取込できます。「続きのページを追加」から、新しい章のページ割りと字コンテを作れます。同一作品24ページまで。字コンテは1回1〜4ページ（自動作成は2ページずつ）で、各回は新しいStrataセッションですが、台帳・直前のページ・引継ぎを渡します。

操作の詳細は [編集ワークスペース](docs/guides/EDITING_WORKSPACE.md)。新作の原作は [星を返す郵便局](examples/star-post-office.txt)、変更前後の結果は [改稿試験](docs/records/REVISION_TRIAL.md) にあります。

使い方は生成方式ごとに分けました。**どちらも単独で、起動・原稿入力から編集・生成・書出しまで読めます。**

| 生成方式 | 使い方ガイド |
|---|---|
| コマごとに画像を作り、枠と台詞を後付けする | [コマ別生成 — 4ページずつ進める制作](docs/guides/FOUR_PAGE_WORKFLOW.md) |
| コマ枠を含むページ全体をNovelAIで1枚に描く | [ページ一括生成 — 文章／JSON／YAML・文字方式・修正](docs/guides/WHOLE_PAGE_WORKFLOW.md) |

どちらの方式も、ページ割りで原作を各ページへ割り振ってから字コンテを作ります（2026-10-17以降。上の2つのガイドはそれ以前の手順を含みます）。ページ一括方式の画像生成は1ページずつです。公開時に使う [note記事の下書き](docs/guides/NOTE_ARTICLE_DRAFT.md) はコマ別方式の制作例を扱っています。

NovelAIの小説機能に原作を依頼するときは、[通常小説用・字コンテ用のシステム指示と使い方](examples/NOVELAI_WRITING.md) を利用できます。どちらも、見える動作・表情・背景と固定設定を重視します。通常小説用は章見出しで区切る形で、ページ数はこのツールのページ割りで決めます。

NovelAI小説APIから字コンテを生成して作った8ページ「陸上とスニーカー」（女子陸上部員3人の部活動からバス移動、デパートでの靴選び）の制作記録は [こちら](docs/records/TRACK_SHOPPING_TRIAL.md)。小説生成は検証用の外部呼出しで、Sに機能追加していません。

Seed空欄は毎回ランダム。過去と同じSeedは候補ボタンの説明または要求JSONから確認できます。クロップ横・縦は0〜1で、0が左／上、1が右／下です。画像が枠より縦長なら、クロップ縦を0へ寄せると頭部を残せます。

保存用IDは英数字です。日本語の作品名とは別に `rain-story` などを付けます。原作全体は最大200,000文字、今回選択した章は共通設定込み30,000文字以内。`## 第一章` のような見出しで区切ると章を選べます。最初の見出しより前は毎回渡す共通設定です。見出しなしなら全体を1区間として扱います。12ページ原作の例は `examples/rain-lantern-12.txt`。NovelAI小説用の字コンテ指示は `templates/novelai-storyboard-system.txt`。その出力を原作として貼る方法と、`templates/board.example.json` 形式の新規JSON取込にも対応します。

## 保存先

| 場所 | 内容 |
|---|---|
| `work/<id>/source.txt` | 原作の参照用コピー（新UIの保存元はproject.jsonのsource） |
| `work/<id>/project.json` | 編集の正本、人物台帳、プロンプト、採用画像 |
| `work/<id>/history/` | 保存前の作品JSON |
| `work/<id>/images/<コマID>/` | 候補PNG、送信要求、生成前後の残量記録 |
| `work/<id>/output/page-001.png` | 台詞を合成した完成ページ |
| `work/<id>/output/overview.png` | 全ページの一覧画像 |
| `work/<id>/output/manifest.json` | ページ寸法、コマ矩形、元画像、クロップ、文字位置。PSD作成への引渡し用 |
| `work/<id>/agent-runs/` | Strataのツール実行履歴 |
| `work/<id>/exports/<id>/download.zip` | バックエンド作成のPNG／PSD・台詞md・設定JSON・配置情報 |
| `.runtime/anlas-ledger.json` | 全作品共通の検証費用台帳 |

バックアップは `work` と `.runtime/anlas-ledger.json` を含めてください。作品・キー・実行環境はSVNの既定対象から外しています。作品のSVN管理が必要なら別途対象を選びます。

## 現在の範囲

- 84種のコマ割り（従来5＋A由来79）、1ページ1〜7コマ、固定1200×1800ページ。斜め枠も組版します。フキダシはPillowの横組みで、HTMLは完成PNGを表示します。自由ドラッグの枠編集・縦組みは未実装です。
- 人物の外見・口調、背景・小物、絵柄、コマ数はUIから編集可能。日英は別々に保存し、翻訳と改稿は明示操作です。Strata改稿は1ページずつ処理し、成功後に終了します。
- PSDの文字は分離したラスターレイヤーです。psd-toolsによる再読込・合成一致は検証済みですが、Photoshop／CLIP STUDIOでの実読込とネイティブ文字編集は未検証・未対応です。
- NovelAI V5 Curated、23steps、1枚、標準サイズだけに制限しています。Opus有効性・V5枠を確認し、不足なら停止。有料へ自動で切り替えません。検証上限5000 Anlasより保守的に、予期しないAnlas減少を1回検知した時点でも停止します。
- Strataには画像を渡しません。人物の左右、傘などの小物の数、手、台詞の因果関係は人が確認します。画像を生成できたことと、作画の正確さは別です。
- 24ページまで固定設定を共通利用しますが、同じ文章だけで顔や背景の形が完全一致する保証はありません。画像参照による強化、長編の自動章分割は今後の対象です。NovelAI小説APIは今回限定の外部スクリプトで検証し、アプリの機能には含めません。

## ページを1枚で生成する

作品の作成画面で、生成方式に **ページ一括生成（試験）** を選びます（既存の作品は、作品専用タブ「作品の管理」の「生成方式を変更（上級）」）。ページ設計JSONを確認し、「送信形式」で漫画用の文章・JSON・YAMLを選び、「保存して1ページ生成」を押します。JSON/YAMLはプロンプトへの書き方の比較用で、NovelAI公式の専用漫画スキーマではありません。

「フキダシと文字」を「後付け」にするとアプリの台詞を分離できます。「NovelAIが画像内へ描く」では台詞修正も再生成が必要で、台詞なし出力はできません。後付けでもモデルが余計な文字を描く場合は原画に残ります。また生成された枠はテンプレートの厳密な位置と一致する保証がありません。枠・文字配置を優先する制作はコマ別方式が適しています。既存のコマ別画像とページ候補は保持します。

同じ1ページを3形式で試した比較は検証記録にあります。現行UIで作った作品は通常のコマ編集とページ設計が連動します。独立した設計が残る旧作品は「元コマから作り直す」で取り込めます。手順は [ページ一括生成の使い方](docs/guides/WHOLE_PAGE_WORKFLOW.md)、形式比較と技術上の制限は [検証記録](docs/records/WHOLE_PAGE_MODE.md) を参照してください。
