基本の使い方

ローカルのQwenImage 2.1も選べます。作品作成時に画像モデルを選択します（作成後は固定）。作品専用タブで参照画像の利用を選べます。Qwenの準備・プロンプト・Anima仕上げ。NovelAIを使う手順は以下を参照してください。

小説を貼り付けてから、完成ページを書き出すまでの流れです。はじめての方は、上から順に読みながら操作してください。

このツールでできること

あなたの小説を、制作AI（Strata／Grok）がページとコマに分け、画像モデル（NovelAI／Qwen）がコマの絵を描き、ツールが枠と台詞を付けてページに仕上げます。

小説→ページ割り→字コンテ→コマの絵→組版→PNG／PSD
担当すること
あなた小説を用意する。絵柄を選ぶ。字コンテと絵を確認して直す。採用するかを決める。
Strata／Grok（制作AI）原作をページへ割り振る（ページ割り）。字コンテ（ページごとのコマ割りと、各コマの場面・登場人物・台詞・話者を文字で決めたもの）と、画像モデルへの英語の指示（プロンプト）を作る。生成前の点検や翻訳も行う。Strataはローカル、Grokはクラウドで動く制作AIです。
NovelAI／Qwenコマの絵を1枚ずつ描く。
ツール画像生成の要求を送り、履歴とNovelAIのAnlas残量差を管理。組版（コマの絵を枠に並べ、台詞の吹き出しを載せてページに仕上げること）。完成ページのPNG・PSDの書き出し。

物語の良し悪しや絵の採否は、人が見て決めます。ツールが確認するのは「作れたこと」までで、作る途中でエラーになった場合は画面にメッセージを表示します。

中でしていること（ざっくり）

画面のボタンを押すと、ツールの中では次のことが自動で行われます。仕組みの説明で、設定で切り替えるものではありません。

  • 選択した制作AIへは、作業を2段階に分けて指示します。
    1. ページ割り：原作（開始する章から最後まで）を1回で渡し、各ページに描く出来事と台詞を決めさせます。
    2. 字コンテ：ページ割りの割り当てに従って、2ページ前後ずつ、コマ割り・各コマの場面・台詞・話者と、画像モデル用の英語の指示を作らせます。
    字コンテを指示するときは毎回、人物・背景・小物の設定（作品専用タブの「キャラクターの外見・口調／背景／小物」に並ぶ、人物の外見・口調・服、背景、小物の特徴）、直前のページ、前回の引継ぎメモを一緒に渡します。同じ設定を継続して渡しますが、出力の一致は人が確認します。
  • 画像モデルへは英語で指示します。制作AIが日本語の原作から英語の指示を作ります。日本語訳の欄は確認用です。台詞を画像内へ描く方式では、日本語の台詞も画像モデルへ送ります。
  • 人物・背景・小物の設定は、コマごとに自動で付け足します。画像モデルは前のコマを覚えていないので、コマの絵は1枚ごとに独立した指示で描かれます。そこでツールは、コマの絵を指示するたびに、次の内容をそのコマの指示に付け足して送ります。
    • 作品の絵柄（作品専用タブの「絵柄」）
    • そのコマに出る人物の外見と、そのコマで選んだ服
    • そのコマの背景と、チェックを入れた小物の特徴
    コマごとの指示（ページ／コマ個別タブ）には、そのコマの構図・動作・光だけを書きます。人物・背景・小物の設定を直すと、次に描くコマから全部に効きます（描き済みのコマは、描き直すまで変わりません）。
  • 基本は1コマずつ描きます。コマの形に合わせて縦長・横長・正方形から大きさを選び、作品で選んだ画像モデルで1枚ずつ描きます（コマ別生成）。NovelAIでは人物を1人ずつ分けて位置を添え、Qwenでは位置も文章で指定します。作品を作るときに「ページ一括生成（試験）」を選ぶと、画像モデルがコマ割りを含む1ページを1枚で描きます。こちらは実験的な方式で、コマの境目や台詞の位置が指定どおりになるとは限りません。

はじめる前に

Windows・PowerShell・Python 3.12・ブラウザを用意し、取得したフォルダで python -m pip install -r requirements.txt を実行します。Python 3.12.10での動作記録があり、他のPython版・OSは未検証です。

1. 制作AIを選んで準備する

  • Strata：別途構築し、既定では 127.0.0.1:8080 で起動します。接続先URL・モデル名はアプリ直下の .env で変更できます。設定方法・準備・接続条件。
  • Grok：公式CLIを導入し、このPCでログインします。Strataは不要です。Windowsへの導入・ログイン。

アプリを開いたら、最初のAI操作の前に「汎用」タブの「制作AI」で選びます。Grok選択時はボタン内の「Strata」が「Grok」へ変わります。このガイドではStrata選択時のボタン名を例にします。CLIが選択可能でも、ログインや利用枠が有効とは限りません。

2. NovelAIのAPIトークンを .env に書く（NovelAIを使う場合のみ）

このツールはNovelAIへ画像を頼むとき、あなたのNovelAIアカウントのトークンを使います。NovelAIの接続・残量確認と画像生成に必要です。アプリの起動・編集・制作AIの文章処理には不要です。Qwenだけを使う場合は、この手順を飛ばして ComfyUIとモデルを準備します。

  1. NovelAIを開き、右上の歯車のアイコン（設定）› アカウント（Account）› 永続的APIトークン（Get Persistent API Token） を押します。上書きの確認が出たら 上書き（Overwrite） を押し、表示されたトークンをコピーします。ウィンドウを閉じると二度と表示されないので、先に次の手順で保存します。（括弧の中は、NovelAIを英語表示にしているときの名前です）
  2. このツールのフォルダ（start-studio.cmd と同じ場所）に .env がなければ、.env.example をコピーして .env に変えます。既存の .env はそのまま編集します。
  3. .env をメモ帳で開き、NOVELAI_API_KEY= の = の後ろに、コピーしたトークンを貼り付けて保存します。
    NOVELAI_API_KEY=ここにトークンを貼る
トークンはパスワードと同じです。人に見せたり、共有フォルダやGit・SVN・公開リポジトリに入れたりしないでください。このツールはトークンをサーバー側で読み、制作AIの入力に含めません。原作やプロンプトへトークンを貼り付けないでください。作品・履歴・設定JSONを共有するときは、内容に機密情報がないか確認します。NovelAIで新しいトークンを作ると古いトークンは使えなくなるので、そのときは .env も書き換えます。

3. 起動する

  1. 制作AIにStrataを使うならStrataを起動し、Grokを使うならログインを済ませます。Qwenで画像生成する場合はComfyUIも起動します。
  2. start-studio.cmd をダブルクリックします。このツールだけを起動します。黒い画面は、使っている間は閉じないでください。
  3. ブラウザで http://127.0.0.1:8765 を開きます。

Strataが応答しないという起動時の表示が出ても、アプリ自体は開けます。Grok選択時はStrataを起動する必要はありません。

4. つながっているか確かめる

  1. NovelAIは右上の 接続・残量を確認 を押し、契約・残量・V5利用枠を確認します。エラーなら .env と契約状態を見直します。Qwenは作品作成後の「作品専用」タブの 接続確認 を使います。どちらも制作AIの疎通確認とは別です。
  2. 右上の 検証 0 / 5000 Anlas は、全作品のNovelAI生成前後のAnlas残量差の累計と、変更可能な上限です。0に戻した後はそこから数えます。生成枚数・請求明細・V5利用枠・Grokの料金ではありません。合計が上限に達すると次のNovelAI生成を止めます。上限の変え方は 費用と安全のしくみ にあります。

作り方（10ステップ）

所要時間は制作AI・PC・サービスの混雑・作品の内容で変わります。StrataとGrokを区別した 過去の所要時間の参考値があります。

1. 小説を用意する

このツールに渡す小説は、最初に「共通設定」（人物の外見・口調・服・場所・小物）を書き、その後に ## 第一章　タイトル のような見出しで章を区切ると、うまくいきます。章は場面の大きな区切りで、長さを揃える必要はありません。

書き方のコツは 渡す小説のコツ、NovelAIに書いてもらう方法は NovelAIで小説を書く にあります。

2. 作品を作る

  1. 左の ＋ を押します。
  2. 作品名（日本語でよい）と、保存用ID（英数字と - _。例 lost-camera）を入れます。
  3. 画像モデルにNovelAIまたはQwenImage 2.1 Turboを選びます。作成後は変更できません。
  4. 生成方式は、はじめは コマ別生成・後から組版 を選びます（コマごとに絵を作り、台詞をあとから載せる方式）。
  5. 原作を貼り付けて 作品を作成（まだ生成しません） を押します。この時点ではAIも画像生成も動きません。

3. 絵柄を選ぶ

右の「作品専用」タブ › 絵柄（プリセット・共通の除外）

絵柄プリセット から選び、設定を保存 を押します。英語の欄が画像モデルへ送られ、日本語の欄は確認用です。白黒にしたい場合は「かわいいモノクロ漫画」などのモノクロ系を選びます。

4. ページ割りを作る

中央の「字コンテを作成」カードの 1. ページ割り を使います。原作のどの部分を何ページ目に描くかを、選択した制作AIが1回で決めます。対象原作・共通設定・引継ぎ・依頼等を含む入力JSON全体が90,000文字以内である必要があります。保存上限との違い。

  1. 開始する章（はじめは第一章）と、全体のページ数を入れます。目安は本文100〜150字で1ページです（本文1,500字なら12ページ前後）。1つの作品は最大24ページです（超える場合は 続きを足す・長い作品）。
  2. Strataでページ割りを作る を押します。
  3. 表に各ページの「出来事」「入れる台詞」「コマ数の目安」が出ます。違うところは直接書き換えて保存します。
ページ割りは省略もできますが、使うことをおすすめします。ページ割りがないと、制作AIが前半に場面を詰め込んだり、同じ場面を繰り返したりすることがあります。

5. 2ページだけ字コンテを作って確かめる

2. 字コンテ で「今回作るページ数」を2にして Strataで字コンテを作る を押します。コマの日本語訳は、終わった後に自動で補われます。

できたら次を確認します。

  • 中央のページでコマをクリックし、右の「ページ／コマ個別」で台詞・話者・衣装・背景・小物・表情を見ます。違えば直して 保存・組版（画像生成・制作AIへの送信なし）。
  • 作品専用タブ › キャラクターの外見・口調／背景／小物：人物の外見や服が原作どおりか見ます。
  • 作品専用タブ › キャラ・背景のプロンプト確認／試し描き：人物を1枚だけ描いて、絵柄と外見を確かめられます。Qwenの新規作品は参照モードなので、人物の衣装ごと・背景ごとの試し描きを確認し「参照画像に登録」します。参照を使わない場合は「キャラクター・背景の制御」を「プロンプトのみ」に変えて保存します。

6. 作ったページだけ絵にして確かめる

全ページの字コンテを作る前に、できたページだけ絵にして、絵柄や人物の見た目を確かめられます。問題がなければ飛ばして構いません。

  1. 中央のページ送り（前のページ・次のページ、またはページの選択）で、絵にしたいページを表示します。
  2. このページを生成・組版 を押します。保存と生成の内容が確認画面に出るので、保存して生成 を押します。
  3. そのページの入力だけを点検してから、そのページのコマだけを描いてページに組みます。ほかのページは変わりません。
  4. 人物の見た目や絵柄が違うときは、人物・背景・小物の設定や絵柄を直してから、もう一度押します。ほかのページを作る前に直しておくと、あとの手直しが減ります。

7. 最後まで自動で字コンテにする

ページ割りの最後まで自動で作る を押すと、残りのページを同じ章の中で最大2ページずつ順に作ります。1回の手動作成は1〜4ページです。

  • 途中で止めたいときは 今のページの後で停止。
  • 失敗したらそこで止まります。作成済みのページは残るので、原因を直してもう一度押すと続きから再開します。
  • 終わったら、全ページの台詞と話者に目を通します。生成前に直すのがいちばん安く早い方法です。

8. 点検して、絵を生成する

作品専用タブ › 点検・一括生成

  1. 全ページを生成・組版 を押します。生成前に選択した制作AIとプログラムが入力を点検します。
  2. 警告が出たら読みます。誤った指摘も混ざるので、すべて直す必要はありません。「このページを開く」で該当ページへ移れます。警告をStrataで直す でまとめて直させることもできます。
  3. 問題なければ 警告を無視して生成を続ける。毎回無視するなら「点検の警告があっても無視して生成する」にチェックを入れておきます。
  4. 選択した画像モデルが1枚ずつ描き、ページに組みます。止めるときは 現在の1枚の後で停止。

無視できるのは制作AIの意味上の警告です。入力構造・費用・結果不明による停止は無視できません。通常は未生成・設定変更のある画像だけを生成します。

1ページずつ作りたいときは、手順6と同じく中央の このページを生成・組版 を使います。

9. 仕上がりを見て、気になるコマを直す

  • 中央の下にある「全ページの一覧画像」で全体を見ます。
  • 直したいコマをクリックし、文章を直して 保存して再生成。そのコマだけ描き直します。Seedを空欄にしておくと毎回別の絵になります。
  • 前の絵は「候補」として残り、あとから選び直せます。
  • 自分で書く代わりに、保存してStrataに依頼 に「二人の距離を近づけて」のように頼むこともできます（実際には意図したとおりに変わらない可能性はあります）。
  • 英語の指示に足したい言葉が分からないときは、画像プロンプトの下の 辞書からタグを選ぶ を押します。「向き合う」「天気」のように場面を表す日本語で探して、NovelAIで使える英語のタグを足せます。入れる先（画像プロンプト、除外、人物ごとの動作）は選べます。ページ一括生成の作品では、ページ設計JSONの下にも同じボタンがあり、カーソルの位置に入れます。タグは候補なので、効くかどうかは描き直して確かめます。
  • 台詞や口調をまとめて直すときは、作品専用タブの「既存ページへの修正依頼」と このページをStrataで改稿 を使います。口調だけなら 口調だけ全台詞へ反映 も使えます。
    • 台詞は絵の上に載せる文字なので、台詞だけの直しは絵を描き直さずに反映されます。
    • 改稿でコマの場面や英語の指示も変わったときは、そのコマが「設定変更あり」になります。絵に反映するには、そのコマを描き直します。
    • ページ一括生成で「画像モデルが画像内へ描く」を選んだ作品では、台詞も絵の一部なので、台詞を直したら描き直しが必要です。

絵が思いどおりにならないときは 画像生成のTips を見てください。

10. 書き出す

作品専用タブ › 画像・PSD書き出し／設定JSON

形式（PNG、またはPSD＋確認用PNG）と台詞あり／なしを選び、全ページを書き出す。ZIPがダウンロードされます。台詞一覧（dialogue.md）と設定JSONも入ります。PSDの文字はラスターレイヤーで、ネイティブ文字編集はできません。psd-toolsの再読込・合成一致には検証記録がありますが、Photoshop／CLIP STUDIOでの実読込は未検証です。原画へ描き込まれた文字は、台詞なし出力でも消せません。

続きを足す・長い作品

  • 原作に続きを足すときは、作品専用タブ › 作品名・原作小説 で、原作の最後に新しい章を書き足して保存します。章は ## で始まる見出しの行から始まり、見出しの名前は自由です（例：## 第四章　帰り道、## 二日目）。それまでの章は消さずに残します。
  • 上の 続きのページを追加 を押し、開始する章を選んでページ割り → 字コンテの順に進めます。前回の終わりと引継ぎメモが表示されます。
  • すでに作ったページや人物の外見は、続きを作るときに書き換えられません。

24ページを超えるとき

1つの作品で作れるのは24ページまでです（このツールの上限です）。それより長い物語は、話（エピソード）ごとに作品を分けて作ります。人物・背景・小物の設定と絵柄は、次の手順で新しい作品へ引き継げます。

  1. 元の作品の作品専用タブ › 画像・PSD書き出し／設定JSON で 引き継ぎ用の設定JSON を押し、ファイルを保存します。絵柄・システムプロンプト・人物・背景・小物だけが入ります（ページと原作は入りません）。
  2. 左の ＋ で同じ画像モデルの新しい作品を作ります（例：作品名「迷子のカメラ 第2話」）。原作には、共通設定と続きの章を入れます。前の話の終わりを、共通設定の最後に2〜3行のあらすじとして書いておくと、話がつながります。
  3. 新しい作品の同じ場所の「設定JSONを取り込む」で、保存したファイルを選びます。
  4. あとは、ページ割りから同じ手順で進めます。ページ番号は1から始まります。Qwenの参照画像は設定JSONに含まれないため、新作品で用意します。
  • 新しい人物・服・場所・小物は、続きの字コンテで制作AIが人物・背景・小物の設定に追加します。それで失敗したときは、先に自分で登録してからやり直すと通りやすくなります（作品専用タブ › キャラクターの外見・口調／背景／小物 の「衣装を追加」など）。

コマ画像の位置を調整する

コマ別生成の作品で、ページ／コマ個別 タブの画像をダブルクリックするか、画像下の 位置調整 を押します。開く前に通常の編集欄は保存されます。

  1. 別画面の画像をドラッグして移動します。横・縦の数値や倍率でも調整できます。コマに白い隙間ができても構いません。
  2. 中央・枠いっぱい で中央の切り抜きに戻し、画像全体を収める で全体が見える倍率にします。
  3. 保存してPNG組版 を押すと画面が閉じ、そのページのPNGと一覧画像を更新します。元画像は残り、書き出すPNG・PSDにも配置が反映されます。キャンセルでは位置を変更しません。

別の画面で作品が更新された場合は上書きせず、競合を知らせます。保存後に組版が失敗した場合は、位置が保存済みであることを画面に表示するので、原因を確認して 再組版 を押してください。

作品一覧を管理する

左の作品レーンの 管理 から操作します。作品を切り替えると、その作品で最後に開いたページに戻ります。初めて開く作品は1ページ目で、表示ページはこのブラウザに記憶されます。

  • 既存フォルダを読み込む：フォルダを選ぶ でこのPCの作品フォルダを選択するかパスを入力し、フォルダを読み込む を押します。project.jsonを持つ対応形式の作品が対象です。別の場所の作品は画像や履歴とともにworkへコピーし、PNGを組版します。元フォルダは残り、同じIDの作品を上書きしません。画像不足や未完了の処理がある場合は読込みを止めます。
  • 一覧から除外する：作品の 除外… を押し、表示される再読込み方法を確認します。確認チェックをONにすると 一覧から除外 が押せます。作品フォルダは削除・移動しません。
  • 除外した作品を戻す：同じ画面の「除外中」から 一覧に戻す を押します。フォルダを移した場合はその場所から読み込み直します。フォルダ自体を削除した場合はバックアップが必要です。

バックアップとゴミ箱への削除は、作品専用タブの「作品の管理（バックアップ・削除）」で行います。

費用と安全のしくみ

Strataはローカル、Grokは対象の原作・台帳・指示・翻訳対象等をクラウドへ送ります。Grokの利用枠・費用はGrok側の契約に従い、NovelAIのAnlas上限では制限しません。NovelAI画像生成は英語プロンプト等を外部へ送り、画像内描画では台詞も送ります。QwenはローカルComfyUIを使いAnlasを消費しません。

右上の「検証」はアプリ内の費用記録の名称です。作品ごとの請求額ではなく、全作品のNovelAI生成（試し描きを含む）前後の残量差を集計します。同時に別画面でNovelAIを利用すると、その減少も含まれます。

上限は次の送信を止めるための値です。すでに行われたサービス側の消費を取り消すものではなく、請求額が必ず上限内に収まる保証ではありません。

  • このツールは、Opus契約で追加のAnlasがかからない設定（V5 Curated、標準サイズ、23ステップ、1枚ずつ）だけで生成するように作られています。NovelAI側の条件が変わることもあるので、生成の前後に右上の表示とNovelAIの残量を確かめることをおすすめします。
  • 無料範囲が使えないときは止まり、有料に自動で切り替えません。
  • 検証費用の上限（既定5000 Anlas）は変えられます。右上の 検証 0 / 5000 Anlas を押すと設定の画面が開きます。
    • 上限を変える：「上限（Anlas）」に数字を入れて 上限を変更。
    • 合計を0に戻す：合計を0に戻す… を押して確認します。戻した日時と、戻す前の合計は「変更の履歴」に残ります。各生成の記録は消えません。
    • 送信結果が分からない生成や、思わぬ残量の減少で止まっているときは、0に戻しても解除されません。送信結果が不明になったとき、予期しないAnlasの減少で止まったときの手順で確かめます。
    • 画像の生成中は変えられません。終わってから操作します。
  • 送信の結果が分からないとき（通信の途中で切れたなど）は、同じ絵を自動で送り直しません。
  • 処理は1つずつ順番に行います。処理中は他のボタンが押せません。
  • 変更のあった作品は、起動時と30分ごとに自動でバックアップされます（画像を除く軽量版）。作品の削除は「ゴミ箱」フォルダへの移動です。

困ったとき

こうなったこうする
ページ割りや字コンテが失敗した赤いメッセージを読みます。制作AIの処理は形式エラー等の修正回数に上限があり、通信失敗・時間切れは自動再送せず止まります。新しい服・場所が足りないなら人物・背景・小物の設定に登録し、ページ割りの内容がおかしければ表を直してから、もう一度押します。
台詞や話者が違うそのコマを開いて直接直し、保存・組版。
隣のコマに同じ台詞がある点検で警告されます。台詞を分けるか、片方を消します。
絵が気に入らないコマを選んで 保存して再生成。何度か試して候補から選びます。
「編集競合」と出た別の場所で保存されています。読み直す を押してからやり直します。未保存の内容は先に控えてください。
「処理中」が長い字コンテは1回1分以内、生成は1枚10〜20秒が目安です。ブラウザを再読み込みしても処理はサーバーで続きます。
送信結果が不明・「要確認」と出た画像と残量を確かめる。同じ生成を送り直さないでください。
予期しないAnlasの減少で止まった停止理由と残量を確かめる。合計を0に戻しても解除されません。
強制終了したあと、処理が始まらない処理中の印が残っていないか確かめる。
バックアップから戻したいZIPから作品を戻す。軽量版には画像がありません。
削除した作品を戻したい・完全に消したいゴミ箱フォルダを開く。

送信結果が不明になったとき

通信が途中で切れたときなどは、NovelAIで生成・消費が済んだか、このツールでは確定できないことがあります。同じ要求は自動で再送しません。未確認の生成が1件でも残ると、ほかの作品や試し描きを含め、次の画像生成も止まります。

  1. 右上の検証費用の表示を押し、停止理由と未確認の件数を読みます。合計を0に戻す… では解除されません。
  2. 該当作品を選び、作品専用 タブの 作品の管理（バックアップ・削除） で 作品フォルダを開く を押します。images の中で、対象コマのフォルダ（例 p1-1）、ページ一括なら page-001、試し描きなら previews を開きます。
  3. 生成した時刻付近のPNGを探して開きます。同じ名前の .record.json に生成前後の残量やエラーが残る場合があります。画像があっても費用の確認に失敗していることがあり、画像がなくても未消費とは限りません。
  4. NovelAIの画像生成画面を開き、Anlasの残量とV5の使用量表示を確かめます。このツールでも右上の 接続・残量を確認 を押すと、現在の残量が表示されます。この操作は画像を生成しません。他のタブやアプリでNovelAIを使っていた場合、その消費も残量の差に含まれるので、今回の生成だけの費用とは断定できません。
現在、確認した結果を登録して、この停止を解除する画面・コマンドはありません。画像や残量を確認しただけでは生成を再開できません。作品と .runtime/anlas-ledger.json をコピーして保管し、エラーの文、時刻、確認した画像・残量を添えて開発者へ相談してください。記録の削除や、結果を未消費と決めつける書き換えはしないでください。

予期しないAnlasの減少で止まったとき

追加のAnlasがかからない設定で生成したのに残量が減ると、次の画像生成を止めます。NovelAIの別画面・別アプリでの同時生成や、契約・無料枠の条件を確認してください。このツールが記録するのは生成前後の残量の差であり、NovelAIの請求明細ではありません。

右上の検証費用の表示を押して停止理由を読み、上の手順で画像と生成前後の残量を確かめます。合計を0に戻す… や 上限を変更 を押しても、この停止は解除されません。現在、解除する画面・コマンドはありません。記録を保管して開発者へ相談してください。

強制終了したあと、処理が始まらないとき

PCの電源が落ちた、制作サーバーの画面を閉じたなどの場合、サーバーの処理記録は再起動時に「中断」になり、自動では再開しません。「処理中」と出て新しい操作ができないときは、処理中の印（ロックファイル）が残っている可能性があります。

  1. 同じツールの別画面で、制作AIへの依頼・画像生成・保存・組版が動いていないことを確かめます。制作サーバーを停止し、タスクマネージャーでもこのツールの処理が残っていないことを確認します。判断できない場合は、ファイルを消さず開発者へ相談してください。
  2. エクスプローラーで作品フォルダ work/保存用ID/ を開き、残っている .agent.lock、.project.lock、.compose.lock だけを削除します。画像生成の印はツールのフォルダ内の .runtime/novelai.lock です。作品や費用の記録は削除しません。
  3. 制作サーバーを起動し直し、作成済みのページと右上の検証費用を確認します。送信結果が不明になった画像生成は、印を消しても解除されません。送信結果が不明になったときに従って確認します。

バックアップから作品を戻す

作品専用タブ › 作品の管理（バックアップ・削除）

  1. バックアップフォルダを開く を押し、戻したい日時のZIPを別の場所へ展開します。作品が一覧にない場合は、ツールのフォルダ内の work/_backups/保存用ID/ をエクスプローラーで開きます。
  2. その作品の処理が終わっていることを確認します。work/ に同じ保存用IDのフォルダがある場合は、先に別の場所へ移して保管します。上書きやフォルダの統合はしません。
  3. 展開した中の、project.json が入っている作品フォルダを、フォルダごと work/ に置きます。ブラウザを再読み込みして作品を選びます。

自動バックアップと 今すぐバックアップ（軽量） には画像がありません。絵も戻すには、別に保管した画像か、画像も含めてバックアップ で作ったZIPが必要です。画像が残っていなければ再生成が必要になります。完成ページ・書出しZIPはバックアップに含まれないので、復元後に 再組版 や 全ページを書き出す で作り直します。

ゴミ箱から作品を戻す・完全に消す

  1. 作品専用 タブの 作品の管理（バックアップ・削除） で ゴミ箱フォルダを開く を押します。作品が一覧にない場合は、エクスプローラーで work/_trash/ を開きます。
  2. 戻す作品のフォルダを確認します。例えば rain-story-20261017-123456 は、末尾の日時 -20261017-123456 だけを外して rain-story にします。作品IDに含まれるハイフンは残します。
  3. work/ に同じ名前の作品があれば、その作品の処理が終わってから別の場所へ退避します。ゴミ箱の作品フォルダを work/ へ移し、ブラウザを再読み込みします。

完全に消したいときは、戻す必要がない作品のフォルダであることを確認して、エクスプローラーで削除します。バックアップや全作品共通の費用記録は、作品をゴミ箱へ移しても残ります。
