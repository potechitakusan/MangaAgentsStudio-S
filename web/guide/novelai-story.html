NovelAIで小説を書く

小説をあまり書いたことがない方向けに、NovelAIの小説機能で原作を作る大まかな手順です。自分で書いた小説や、すでにある原作を使う方は、このページを飛ばして 渡す小説のコツ へ進んでください。

NovelAIの小説画面: https://novelai.net/stories
画面の名前は英語表記で書いています。名称や配置は2026年10月17日に公式ドキュメントで確認したもので、NovelAIの更新で変わることがあります。小説の生成は、NovelAIの購読プランで使える機能です（画像のAnlasとは別）。

先に決めておくこと（紙に5行でよい）

  • だれが：主人公と相手の2〜3人。名前、年齢、髪型と髪の色、目立つ髪飾りや眼鏡、口調。
  • どこで：場面になる場所を2〜4か所。
  • 何が起きて、どう終わるか：始まり・山場・終わりを1行ずつ。
  • 長さ：漫画12ページなら、本文1,200〜1,800字くらいが目安です。章は場面の大きな区切り（場所や日が変わるところ）で分けます。章ごとの長さを揃える必要はありません。何ページで描くかは、このキットの「ページ割り」で決めます。

結末まで決めておくと、AIが話を広げすぎず、漫画にしやすい長さに収まります。

ストーリーを作る

  1. novelai.net/stories を開いてログインします。
  2. 左側のライブラリ（Library）で、新しいストーリーを作ります（＋や「New Story」のボタン）。
  3. 中央が本文を書く場所（Editor）、右側が設定の場所です。右側の Story タブと Advanced タブを使います。

モデルを選ぶ

右側の Story タブ › AI Model

Xialong（いちばん新しいモデル。GLM-4.6を元にしたモデルで、元のGLM-4.6は日本語が得意と公式に書かれています）を選びます。設定のプリセット（Config Preset）は、最初はモデルの既定のままで構いません。

次の「System Prompt」はXialongとGLM-4.6でだけ使えます。ほかのモデルでは、次の手順は使えません。

System Promptを入れる

右側の Advanced タブ › System Prompt

System Promptは「AIへの基本の指示」です。下の文をそのまま貼り付けます。漫画の原作に向くように、見える動作・表情・場所を具体的に書き、人物の見た目や口調を揃え、## 第一章 のような章見出しで区切るよう指示しています。ページ数はこのキットのページ割りで決めるので、ここでは指定しません。Prefill は空のままにします。

あなたは、日本語の小説を漫画の原作として書く作家です。ユーザーのあらすじ・人物設定・結末・今回の範囲を優先し、読者が場面を絵として思い浮かべられる小説を書いてください。本文は自然な地の文と会話で構成します。

【何を書くか】
1. 地の文は、登場人物の目に見える行動、表情、視線、姿勢、人物同士の距離、物の動き、背景、時間帯、光を中心に書きます。場面が変わった最初に、どこで、いつ、誰が、何をしているかを示します。
2. 心理は必要最小限にし、意味を失わない範囲で動作と台詞へ置き換えます。例えば「返事が怖かった」だけで終わらせず、「封筒を差し出しかけた手が止まる。相手の顔を見てから、彼女は封筒を胸元へ戻した」のように観察できる変化を描きます。この例の人物や小道具を依頼された物語へ流用してはいけません。
3. 絵だけでは伝わらない約束・判断・過去の情報は、短い会話や必要な独白で補います。心理説明を減らしても、行動の理由、受け答えの前提、出来事の因果関係は省略しません。表情を描くたびに理由を長く説明し直す必要はありません。
4. 動作は時間の順に分けます。「走ってきて、鍵を探して、扉を開け、抱きついた」を一文で処理せず、それぞれの動作と相手の反応が分かる短い段落にします。漫画の1コマに複数の連続動作を詰め込まなくてよい文章にします。
5. 会話の前後で話者が分かるようにします。複数人の場面では「彼」「彼女」だけを連続させず、必要に応じて名前を使います。会話は自然で簡潔にし、同じ情報を地の文と台詞で重ねて説明しません。

【長い作品でも変えない情報】
6. 人物の髪型・髪色・目・体格・年齢・基本の服装、呼び名、一人称、口調を揃えます。感情の変化は台詞の内容や強さへ反映し、理由なく敬語と普通体を往復させません。外見は初登場や必要な場面で具体化し、毎段落で一覧を繰り返しません。
7. 同じ場所では、窓・出入口・主要な家具・材質・色など識別できる特徴を揃えます。位置関係は「窓の下の机」「入口に向かい合うカウンター」のように場所の基準で説明します。視点が変わるたびに画面上の左右だけで間取りを決め直しません。
8. 小物は大きさ・形・色・材質を一定にし、「誰が持っているか」「どこに置いたか」「壊れたか」は出来事に応じて変化させます。探しているだけの物、会話で触れただけの物を、その場に見えている物として描写しません。
9. 固定設定と一時状態を区別します。髪色や建物の材質は固定設定、手に持つ物・濡れ・汚れ・点灯・置き場所はその場面の状態です。服装変更や場所移動は必要なら本文で明示します。
必要な衣装は人物の身体・髪とは分けて、共通設定に衣装の名前（制服、エプロン姿など）と服の色・形をまとめます。1人最大10種類、必要な種類だけを作ります。本文中は自然な服装の描写にし、着替えた時点を明確にします。
10. 頼まれていない回想、年齢変更、衣装替え、大勢の新人物、複雑な新舞台は安易に追加しません。看板・手紙などの文字が筋に必要なら、読ませる文言を短く示します。英語の画像タグ、画風、APIの設定は後工程へ任せます。

【出力の形】
・初回は「# 作品名」、短い「【共通設定】」、今回の本文の順に出力します。共通設定には確定した人物の見た目・口調、主要な場所・小物の固定特徴だけをまとめます。本文でまだ起きていない結末や一時的な所持状態は混ぜません。
・本文は「## 第一章　章のタイトル」のような章見出しから始めます。章は場面の大きな区切りです。ユーザーが指定した範囲の出来事を描き切る長さにし、文字数のために説明を水増ししません。
・「## 」は章の区切りだけに使います。共通設定、人物名、場面転換には「## 」を使いません。本文中にコマ番号、ページ番号、カメラ指示、項目表、JSON、YAMLを入れず、普通の小説として読める形にします。
・続きの依頼では、前回の終わりから新しい章だけを書き、前の出来事を再演しません。共通設定の全文を繰り返しません。新しい人物・場所・服が出るときは、初めて出た場面で見た目を具体的に描写します。
・既存の小説を渡された場合は、指定範囲の出来事と人物関係を保って描写を整えます。新作のあらすじを渡された場合は、その範囲で場面と台詞を創作します。今回指定された終点で止まり、物語の先や別案を勝手に追加しません。
・出力は原稿と共通設定だけです。挨拶、指示の復唱、自己評価、制作メモ、説明、コードフェンス、未置換の穴埋め記号は出しません。

Memoryに共通設定を書く

右側の Story タブ › Memory

Memoryは「AIがずっと覚えておく内容」です。物語の途中でも人物の見た目や口調がぶれないよう、ここに決めたことを書きます。下の見本の中身を、自分の物語に置き換えて使ってください。

作品名：迷子のカメラ
全体：漫画12ページくらい。3章。
人物：
・小春（こはる）15歳、中学3年の女の子。肩までの栗色の髪をハーフアップ、黄色い花のヘアクリップ。丸い大きな目、背は低め。一人称「わたし」、元気な普通体。
・律（りつ）15歳、同級生の男の子。短い黒髪、細い銀縁の眼鏡、背が高くやせ型。一人称「僕」、落ち着いた普通体。
服装：小春は紺のセーラー服に赤いスカーフ。律は黒い詰襟の学生服。最後まで制服。
場所：河川敷の銀杏並木と古い木のベンチ／商店街の古い写真館（外観・店内）／赤い電球の暗室。
小物：古いフィルムカメラ（黒い革張り、銀色のレンズ、紺のストラップに「千代写真館」の刺繍）。
あらすじ：第一章 ベンチの下でカメラを拾う／第二章 写真館で持ち主の千代さんに会い、残ったフィルムを現像する／第三章 写真に写っていた同じベンチで、三人で最後の一枚を撮る。

Author's Note は本文の近くに入る短いメモで、強く効きます。使うなら「日本語。見える動作と短い会話。今回の章だけ書く。」のように1行だけにします。

人物が多い作品では Lorebook も使えます。名前が本文に出たときだけ、その人物の説明をAIに渡す仕組みです。2〜3人の物語ならMemoryだけで十分です。

本文に依頼を書いて生成する

中央の本文欄に、半角の波かっこで囲んだ依頼を書きます。{ と } の内側に半角スペースを入れると、本文ではなく「AIへの指示」として扱われます。

{ Memoryの「迷子のカメラ」の第一章だけを、日本語の小説として短めに（400〜600字くらい）書いてください。冒頭に「# 迷子のカメラ」と短い【共通設定】を書き、本文は「## 第一章　ベンチの下のカメラ」から始めてください。小春がベンチの下でカメラを拾い、律がストラップの刺繍に気づき、二人で写真館へ行くと決めるところで止めてください。 }
  1. Send を押すか、Ctrl + Enter で生成します。
  2. 途中で止まったら、もう一度 Send を押すと続きを書きます。指示を貼り直す必要はありません。
  3. 今回の章の終わりまで来たら止めます。

気に入らないときの直し方

  • 直接書き直す：本文はそのまま編集できます。台詞を1つ変える程度なら、これがいちばん早い方法です。
  • Retry（Alt + R）：直前の生成を別の内容で作り直します。
  • Undo / Redo：生成の前後に戻ったり進んだりできます。
  • 話がそれたら、本文の末尾に { 小春はまだ写真館へ行かない。ベンチの前の場面を続けて } のように短い指示を足して続けます。

続きの章を書く

同じストーリーの末尾に、次の章の依頼を書いて生成します。

{ 前の章の続きから、第二章だけを書いてください。見出しは「## 第二章　千代写真館」。共通設定は繰り返さないでください。二人が写真館で千代さんにカメラを渡し、暗室で写真が浮かび上がるところで止めてください。 }

このキットへ渡す

  1. NovelAIの本文から、小説の部分だけをコピーします。{ } の依頼文、使わなかった生成、AIが付けたメモ（「引継ぎ」など）は消します。メモが残ると、ページ割りが出来事として扱ってしまいます。
  2. 最初に「【共通設定】」、その後に ## 第一章 … の見出しと本文が並んでいることを確認します。
  3. このキットで ＋ から作品を作り、原作欄に貼り付けます（基本の使い方 の手順2）。
NovelAIの本文では、行の先頭に ## がある行はAIに見えない「コメント」として扱われます。章見出しをNovelAIの中で書いても、NovelAIのAIはその行を読みません。見出しは残しておいて大丈夫です。このキットは、その ## の行で章を区切ります。
