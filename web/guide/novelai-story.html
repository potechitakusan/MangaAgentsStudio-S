NovelAIで小説を書く

小説をあまり書いたことがない方向けに、NovelAIの小説機能で原作を作る大まかな手順です。自分で書いた小説や、すでにある原作を使う方は、このページを飛ばして 渡す小説のコツ へ進んでください。

NovelAIの小説画面: https://novelai.net/stories
画面の名前は英語表記で書いています。名称や配置はNovelAIの更新で変わることがあります。公式の設定説明も確認してください。小説の生成は、NovelAIの購読プランで使える機能です（画像のAnlasとは別）。

先に決めておくこと（紙に5行でよい）

  • だれが：主人公と相手の2〜3人。名前、年齢、髪型と髪の色、目立つ髪飾りや眼鏡、口調。
  • どこで：場面になる場所を2〜4か所。
  • 何が起きて、どう終わるか：始まり・山場・終わりを1行ずつ。
  • 長さ：漫画12ページなら、本文1,200〜1,800字くらいが目安です。章は場面の大きな区切り（場所や日が変わるところ）で分けます。章ごとの長さを揃える必要はありません。何ページで描くかは、このキットの「ページ割り」で決めます。

結末まで決めておくと、AIが話を広げすぎず、漫画にしやすい長さに収まります。

ストーリーを作る

  1. novelai.net/stories を開いてログインします。
  2. 左側のライブラリ（Library）で、新しいストーリーを作ります（＋や「New Story」のボタン）。
  3. 中央が本文を書く場所（Editor）、右側が設定の場所です。右側の Story タブと Advanced タブを使います。

モデルを選ぶ

右側の Story タブ › AI Model

Xialong（このガイドで使うモデル）を選びます。設定のプリセット（Config Preset）は、最初はモデルの既定のままで構いません。

次の「System Prompt」は公式資料でXialongとGLM-4.6への対応が案内されています。ほかのモデルでは、次の手順は使えません。

System Promptを入れる

右側の Advanced タブ › System Prompt

System Promptは「AIへの基本の指示」です。下の文をそのまま貼り付けます。漫画の原作に向くように、見える動作・表情・場所を具体的に書き、人物の見た目や口調を揃え、## 第一章 のような章見出しで区切るよう指示しています。ページ数はこのキットのページ割りで決めるので、ここでは指定しません。Prefill は空のままにします。

あなたは漫画の原作を書く小説家です。ユーザーの設定・あらすじ・指定範囲を守り、日本語の自然な地の文と会話で書きます。
・見える動作、表情、視線、人物の位置、背景、光を中心に書く。気持ちは動作と台詞で表し、行動の理由と因果は残す。
・続けて起きる動作は短い段落に分け、話者が分かるよう名前を使う。
・人物の外見・服装・口調、場所と小物の特徴を最後まで揃える。服を替えるときは本文で明示する。
・頼まれていない回想、新しい人物、新しい舞台を足さない。

【出力の形】
・初回は「# 作品名」、短い「【共通設定】」（人物の見た目・服装・口調、場所と小物）、本文の順。
・本文は「## 第一章　章のタイトル」の見出しで始める。「## 」は章見出しにだけ使い、ページ番号・コマ番号・カメラ指示・表は書かない。
・続きは新しい章だけを書き、共通設定を繰り返さない。指定された終点で止める。
・原稿以外（挨拶、指示の復唱、メモ、説明）は出さない。

この文は、キットの examples/novelai-visual-novel-system.txt と同じです。

Memoryに共通設定を書く

右側の Story タブ › Memory

Memoryは「AIがずっと覚えておく内容」です。物語の途中でも人物の見た目や口調がぶれないよう、ここに決めたことを書きます。下の見本の中身を、自分の物語に置き換えて使ってください。

作品名：迷子のカメラ
全体：漫画12ページくらい。3章。
人物：
・小春（こはる）15歳、中学3年の女の子。肩までの栗色の髪をハーフアップ、黄色い花のヘアクリップ。丸い大きな目、背は低め。一人称「わたし」、元気な普通体。
・律（りつ）15歳、同級生の男の子。短い黒髪、細い銀縁の眼鏡、背が高くやせ型。一人称「僕」、落ち着いた普通体。
服装：小春は紺のセーラー服に赤いスカーフ。律は黒い詰襟の学生服。最後まで制服。
場所：河川敷の銀杏並木と古い木のベンチ／商店街の古い写真館（外観・店内）／赤い電球の暗室。
小物：古いフィルムカメラ（黒い革張り、銀色のレンズ、紺のストラップに「千代写真館」の刺繍）。
あらすじ：第一章 ベンチの下でカメラを拾う／第二章 写真館で持ち主の千代さんに会い、残ったフィルムを現像する／第三章 写真に写っていた同じベンチで、三人で最後の一枚を撮る。

Author's Note は本文の近くに入る短いメモで、強く効きます。使うなら「日本語。見える動作と短い会話。今回の章だけ書く。」のように1行だけにします。

人物が多い作品では Lorebook も使えます。名前が本文に出たときだけ、その人物の説明をAIに渡す仕組みです。2〜3人の物語ならMemoryだけで十分です。

本文に依頼を書いて生成する

中央の本文欄に、半角の波かっこで囲んだ依頼を書きます。{ と } の内側に半角スペースを入れると、本文ではなく「AIへの指示」として扱われます。

{ Memoryの「迷子のカメラ」の第一章だけを、日本語の小説として短めに（400〜600字くらい）書いてください。冒頭に「# 迷子のカメラ」と短い【共通設定】を書き、本文は「## 第一章　ベンチの下のカメラ」から始めてください。小春がベンチの下でカメラを拾い、律がストラップの刺繍に気づき、二人で写真館へ行くと決めるところで止めてください。 }
  1. Send を押すか、Ctrl + Enter で生成します。
  2. 途中で止まったら、もう一度 Send を押すと続きを書きます。指示を貼り直す必要はありません。
  3. 今回の章の終わりまで来たら止めます。

気に入らないときの直し方

  • 直接書き直す：本文はそのまま編集できます。台詞を1つ変える程度なら、これがいちばん早い方法です。
  • Retry（Alt + R）：直前の生成を別の内容で作り直します。
  • Undo / Redo：生成の前後に戻ったり進んだりできます。
  • 話がそれたら、本文の末尾に { 小春はまだ写真館へ行かない。ベンチの前の場面を続けて } のように短い指示を足して続けます。

続きの章を書く

同じストーリーの末尾に、次の章の依頼を書いて生成します。

{ 前の章の続きから、第二章だけを書いてください。見出しは「## 第二章　千代写真館」。共通設定は繰り返さないでください。二人が写真館で千代さんにカメラを渡し、暗室で写真が浮かび上がるところで止めてください。 }

このキットへ渡す

  1. NovelAIの本文から、小説の部分だけをコピーします。{ } の依頼文、使わなかった生成、AIが付けたメモ（「引継ぎ」など）は消します。メモが残ると、ページ割りが出来事として扱ってしまいます。
  2. 最初に「【共通設定】」、その後に ## 第一章 … の見出しと本文が並んでいることを確認します。
  3. このキットで ＋ から作品を作り、原作欄に貼り付けます（基本の使い方 の手順2）。
NovelAIの本文では、行の先頭に ## がある行はAIに見えない「コメント」として扱われます。章見出しをNovelAIの中で書いても、NovelAIのAIはその行を読みません。見出しは残しておいて大丈夫です。このキットは、その ## の行で章を区切ります。
