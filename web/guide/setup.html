Strataの準備

Strataは別途構築するローカルの制作AIです。Grokだけを使う場合は不要です。導入には公式Strataの手順を使います。アプリの start-studio.cmd と Start-Studio.ps1 はStrataを起動しません。

項目アプリの接続条件
接続先既定は http://127.0.0.1:8080/v1/chat/completions。LOCAL_AI_URL で変更可能。OpenAI互換のツール呼出し（function calling）が必要。
モデル名既定は qwen3.8-flash-next-iq2_xs。LOCAL_AI_MODEL で変更可能。下記構成での利用記録であり、他のモデルの互換性を保証しない。
生成パラメータtemperature: 0.2、max_tokens: 8192、stream: false、reasoning_effort: none（Thinkingオフ）。
応答時間1応答は最大180秒。字コンテ作成・コマ修正のツール往復は8ターン・10分まで。ページ割り・翻訳・点検等は別の短い処理で、形式修正を含め最大2応答。それぞれ180秒まで。
入力とコンテキストコンテキスト128K以上を推奨。アプリが要求する固定の最低値ではなく、最大入力時の成功保証でもない。文字数による別の入力制限がある。

構築済みのStrataフォルダで実行する起動例です。strata-iq2_xs.json はStrata側の設定ファイルで、このアプリには含まれません。構築時の名前に合わせてください。

.venv\Scripts\python.exe -u serve/server.py --engine strata --config strata-iq2_xs.json --host 127.0.0.1 --port 8080

PowerShellで状態を確認します。loaded が true になるまで待ちます。モデルの読込みには数分かかることがあります。

Invoke-RestMethod http://127.0.0.1:8080/health

アプリの「汎用」タブの「制作AI」で「Strata」を選びます。Strataの状態確認はモデルの読込みまでの確認です。原作からの生成成功や、物語・絵の品質の保証ではありません。

接続先・モデル名を .env で設定する

実行するアプリの start-studio.cmd と同じフォルダの .env を使います。Publish版ならPublish内です。作品フォルダの .env は読みません。ファイルがなければ .env.example をコピーし、既にあれば必要な行だけ追記・編集します。UTF-8で保存してください。

LOCAL_AI_URL=http://127.0.0.1:8080/v1/chat/completions
LOCAL_AI_MODEL=qwen3.8-flash-next-iq2_xs

これは既定値の例です。ホスト名・ポート番号をサーバーに合わせ、モデル名はサーバーが公開するID（または別名）に合わせます。URLは /v1 だけでなく /chat/completions まで含めます。HTTP／HTTPS、IPv6、リバースプロキシのパス接頭辞に対応します。URLへのユーザー名・パスワード・クエリの埋込み、リダイレクト、APIキー認証には対応しません。OSのHTTPプロキシは使いません。

OSの同名環境変数が .env より優先し、未設定・空欄は既定値になります。同じキーの重複や不正値は通信前にエラーにします。値を引用符で囲むこと、空白の後ろに # コメント を書くことは可能です。変数展開は行いません。進行中の処理を終えてStudioを停止してから編集し、再起動してください。

画面では引き続き Strata を選びます。Grokには適用されません。設定先に原作・台帳・指示を送るため、管理している推論サーバーを指定します。設定値は画面・制作ログ・作品の設定JSONへ書き出しません。Start-Studio.ps1 -Port は画面用ポートで、この接続先とは別です。

起動時には同じ設定からモデル一覧APIへGETで接続します。手動確認も可能で、原作送信や文章生成は行いません。

python -X utf8 -m studio.cli check-local-ai

/v1/chat/completions なら確認先は /v1/models です。一覧に設定したモデルIDがあれば接続確認成功です。一覧APIが未対応の場合は確認できませんが、Studioは起動できます。この確認はツール呼出しの成功を保証しません。

Grok CLIの準備

公式のGrok Build CLIを使います。同名の第三者製CLIとの互換性は確認していません。Windows PowerShell用の導入コマンドは公式案内に掲載されています。導入条件は公式の導入手順も確認してください。

irm https://x.ai/cli/install.ps1 | iex

導入後、新しいPowerShellを開いて確認し、ログインします。

grok --version
grok login

認証はCLIの案内に従います。アプリにはGrok用のキー入力欄はありません。CLIの認証ファイルを作品フォルダや設定JSONへコピーしないでください。

  1. アプリを起動・再読込みし、「汎用」タブの「制作AI」で Grok を選びます。選択はブラウザに記憶されます。
  2. 「Grok（CLI未検出）」なら、grok がPATHで見つかるか確認します。アプリはWindowsでは %USERPROFILE%\.grok\bin\grok.exe も探します。PATHを変更した場合はアプリを起動する端末も開き直します。
  3. 準備後のページ割りや2ページの字コンテ作成が、実際の制作AI接続の確認になります。原作等がクラウドへ送られ、Grok側の利用枠・費用が適用されます。

アプリはジョブごとに独立した短いCLI処理を呼ぶため、対話画面の常駐は不要です。組込みシェル・ファイル操作・別エージェント等は使わせず、限定された保存・検証処理をアプリ側で実行します。失敗時にStrataへ自動で切り替えることはありません。

CLIの確認範囲
